# 受入テストチェックリスト

## 表示

- [ ] PC、スマートフォン、埋め込み先でレイアウトが崩れない
- [ ] ロゴ、色、会社名、リンク、カード画像が案件用になっている
- [ ] カードカルーセルを末尾まで操作できる
- [ ] Markdownリンク、引用、Dify出力画像が表示される
- [ ] 制御トークンや`example.com`が画面に残らない

## 回答

- [ ] サービス一覧、料金、納期、会社情報、採用、問い合わせに回答できる
- [ ] 情報がない内容を推測しない
- [ ] 対象外質問を適切に断る
- [ ] 個別見積もり、クレーム、機密情報を担当者へ誘導する
- [ ] 公式URL以外を生成しない

## 技術・運用

- [ ] `pnpm validate:client`、`pnpm lint`、`pnpm typecheck`、`pnpm build`が成功する
- [ ] APIキーがブラウザJavaScriptやGit履歴に含まれない
- [ ] Dify・Vercel・埋め込み先の3環境で送受信できる
- [ ] 404、API失敗、Dify停止時の表示を確認した
- [ ] 修正窓口、担当者、ログ保存、契約終了時の削除方法が決まっている
