# セキュリティ

- `DIFY_API_KEY`、外部APIキー、個人情報をGitへcommitしません。
- Vercel環境変数はProduction・Preview・Developmentの必要範囲だけへ設定します。
- ナレッジには公開情報または顧客が回答利用を承認した情報だけを登録します。
- カードURLは設定ファイルの許可リストから描画し、LLMが生成したHTMLを実行しません。
- 外部リンクは`noopener noreferrer`付きの別タブで開きます。
- クライアント間でDifyアプリ、APIキー、ナレッジ、Vercelプロジェクトを共有しません。
- ログ・会話履歴・問い合わせデータの保存期間と削除方法を契約前に決めます。
- 個人情報を入力させる場合は、通常チャットではなく目的を限定した安全なフォームを設計します。

公開前に依存関係、Dify権限、Vercelメンバー、GitHub collaborator、埋め込み許可ドメインを確認してください。
