# クライアント導入手順

## 1. 情報収集

- 対象サイトURLと設置ページ
- ボットの目的とKPI
- 回答対象・対象外
- サービス、料金、納期、採用、店舗等の公開情報
- 問い合わせ先と有人対応条件
- ロゴ、ブランドカラー、フォント
- プライバシーポリシーとデータ保持要件

## 2. 公開情報の整理

サイトから抽出した内容は`client/knowledge/`へ整理し、古い情報、推測、社内限定情報を除きます。価格・契約・法務表現は顧客承認を取ります。

## 3. UI設計

標準カードで対応できる範囲を決め、商品検索、予約、地図、フォーム等が必要なら独自レンダラーまたは外部連携として見積もります。

## 4. 実装・受入

Dify、Vercel、埋め込み先の順に接続し、テスト結果と未対応範囲を顧客へ共有します。公開後の修正責任者、反映目安、緊急連絡先も決めます。
